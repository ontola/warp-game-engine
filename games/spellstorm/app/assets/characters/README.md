# Spellstorm's skinned monsters

Bodies with real skeletons and clips, in the format `assets::skinned::Character`
loads. Rebuild them with `tools/import-skins.sh`, which runs the engine's
`gltf_character` converter on the source packs. The sources themselves are not
kept here.

| Files | Source | License |
|---|---|---|
| skeleton, bone_archer, necromancer, gravekeeper | [KayKit Character Pack: Skeletons 1.0](https://github.com/KayKit-Game-Assets/KayKit-Character-Pack-Skeletons-1.0) by Kay Lousberg, www.kaylousberg.com | CC0 (`KayKit-Skeletons-LICENSE.txt`) |

Clips every body has: `idle`, `walk`, `attack`, `hit`, `die`.
