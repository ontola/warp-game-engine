Warp

A Rust game engine for procedural outdoor worlds, built so that a person or a coding agent can change a game and see the result in seconds, with or without a screen.

Two games, one workspace

Sideways

A gravel rally game for GameNight, up to four players on one screen. Cars with suspension, Pacejka tyres and a drivetrain at 120 Hz, stages through dense procedural forest and meadow, engine sound synthesised from the running engine. Warp grew out of it.

Sideways README

Growing Guns

A first-person arena shooter ported from Godot to see what Warp costs a very different game. Procedural castle arenas, 52 cards that grow your rifle, destructible walls, bots, split screen, wave survival and online play. Its cards and rules are Luau that reloads while you play.

What the engine gives a game

PartWhat it doesCrate
Deterministic simulationFixed ticks where the same inputs give the same state, bit for bit. State digests, the first tick where two runs differ, traces of any value over time.kern
Headless renderingEvery frame renders into a texture. The same path runs on a desktop GPU and on a CPU rasteriser, so tests run in a container.render
Scripted playtestsJSON steps that play, run debug commands, capture frames, check state and compare against golden images.app
Cluster rendererCluster LOD selected on the GPU, a visibility buffer, HDR shading in lux and EV100, sun and sky, vegetation, effects, split screen.render
Luau modsSandboxed modules with hot reload, state that survives a reload, and a step budget so a runaway loop stops at the same point everywhere.script
Synthesised soundEngine sound from the running engine, effects playback, and a procedural synth that places voices from mono to 7.1 with distance, air, occlusion and reverb.audio
Online playA host and clients exchanging the game's own messages over iroh, with relays and hole punching.net
PhysicsBox collision and a character mover for gameplay, Rapier rigid bodies for what tumbles and flies.physics

Try it

From a clone of the repository, with stable Rust:

cargo run -p app --example hello
KERN_ADAPTER=software cargo run -p app --example hello -- --shot hello.png
cargo run -p growing-guns-app -- play

The first is a ball rolling over a field in a window. The second renders the same game to a PNG on the CPU. Then read making a game.

Where it stands

Warp is young and changes quickly. The Sideways target, four players on one 4K output at 120 frames per second, is not reached: a controlled four-player route measures about 38 to 44.5 ms per frame with DLSS Quality. There is no editor, and no water, buildings, people or general animation yet. The engineering notes record every measured step, including the ones that were rejected.
