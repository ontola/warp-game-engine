# Warp Humans animation rig

The skeleton Warp Humans are fitted to: `player-rig.json` (joint names,
inverse binds) and `player.anim.bin` (a single two-frame rest clip, the
bind pose). A copy of `games/growing-guns/assets/characters`, built into
the `warp` runtime for Luau games' `humans` (see
`engine/crates/warp/src/humans.rs`). They are posed with the `body` crate's
CC0 captures.

The skeleton comes from the original Growing Guns project's Mixamo-rigged
knight; `provenance.json` records the source hashes. Its pistol animation
clips were removed. The upstream software notice is in
`SOURCE-SOFTWARE-LICENSE.txt`. Third-party asset rights remain with their
original owners.
